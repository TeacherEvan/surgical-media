##Steps
Stage 1: Investigate Subject and Extract Visual Anchors

Before writing a script or rendering frames, research the user's subject and extract concrete technical primitives:

    Deconstruct Core Mechanics: Identify 3 to 5 verifiable facts, equations, architectural failure modes, or quantitative metrics (for example, latency numbers, scaling exponents, geometric ratios, or timeline dates).
    Map Visual Metaphors: Assign every abstract claim to a concrete visual primitive (never leave a scene as static text on a background).
    Select Target Format: Determine the aspect ratio, resolution, frame rate, and duration from the user's prompt or apply defaults:
        Landscape Explainer (YouTube): 1920x1080 (16:9), 60 fps, safe title margin 120px X / 90px Y.
        Vertical Short (Shorts / Reels / TikTok): 1080x1920 (9:16), 60 fps, safe UI margin 90px X / 220px top / 380px bottom (avoids platform caption and button overlays).
        Square Feed (X / LinkedIn): 1080x1080 (1:1), 60 fps, safe margin 80px all sides.

Stage 2: Plan Layout and Audio-First Timing

Always generate or measure audio before locking frame counts so visuals sync to the exact millisecond:

    Draft the Beat Script: Write narration in short, punchy clauses (8 to 15 words per beat) or define non-verbal action beats for stick-figure animations.
    Synthesize Voiceover and Extract Timestamps: Run scripts/tts_align.py (or edge-tts / piper) to generate per-scene WAV files, strip leading and trailing silence, and measure exact durations via ffprobe.
    Partition Canvas Zones: Divide the canvas into non-overlapping regions so captions never collide with diagrams:
        Primary Stage (Top 65% in 9:16, Center 75% in 16:9): Diagrams, stick-figure physics, charts, or code terminals.
        HUD / Metric Header (Top 12%): Section badge, live counter, or timestamp ticker.
        Kinetic Caption Strip (Lower-Third, above bottom safe zone): Word-by-word highlighted subtitles with high-contrast stroke outlines.

Stage 3: Plan Scenes (storyboard.json)

Compile the layout and timing into a deterministic storyboard.json file conforming to references/storyboard-schema.json.

Every scene in storyboard.json must specify:

    scene_id and archetype (geometry_rig, doc_essay, or code_report).
    start_sec and duration_sec derived from the audio track or action timeline.
    camera: Start and end zoom (1.0 to 2.5), pan target (cx, cy), and easing curve (ease_out_expo, ease_in_out_cubic, or spring_pop).
    elements: Ordered list of drawable layers (stick_rig, geometry_construct, system_architecture, code_terminal, scaling_chart, quote_card, kinetic_captions).
    sfx_events: Frame-accurate procedural sound triggers (pop, whoosh, chime, error_buzz, type_click).

Stage 4: Render Frames and Master with FFmpeg

Execute scripts/render_engine.py to synthesize frames and encode the final MP4:

    2x Supersampled Pillow Rendering: Render vector lines, arcs, node graphs, and stick-figure limbs at 2x target resolution (for example, 3840x2160 for 1080p output) and downsample per frame with Image.Resampling.LANCZOS. Pillow's native ImageDraw lacks sub-pixel anti-aliasing on diagonal lines and circles; 2x supersampling eliminates jagged stair-stepping.
    Direct FFmpeg Stdin Streaming: Pipe raw RGBA bytes directly from Python into an ffmpeg subprocess (-f rawvideo -pix_fmt rgba -s WxH -r FPS -i -) instead of writing thousands of PNG files to disk.
    Broadcast Encoding and Loudness Normalization: Encode with H.264 High Profile (-c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p -movflags +faststart) and normalize mixed narration plus SFX to -14 LUFS (-af loudnorm=I=-14:TP=-1.5:LRA=11).
    Automated Verification: Run ffprobe on the output MP4 to verify stream presence, resolution, pixel format (yuv420p), frame rate, and duration parity before delivering to the user.

Gotchas and Quality Guardrails

    Never use linear interpolation (t) for UI or camera motion: Linear movement looks robotic. Always pass normalized time t through ease_out_expo(t) for camera zooms, ease_in_out_cubic(t) for pans, and spring_pop(t) for badge or node appearances.
    Avoid Pillow jagged edges: Never draw thin diagonal lines or circles at 1x resolution. Always instantiate SupersampledCanvas(width, height, scale=2) from scripts/render_engine.py.
    Enforce -pix_fmt yuv420p: Piping RGBA frames into FFmpeg defaults to yuv444p in libx264, which fails to play on iOS, Safari, Instagram, and TikTok. Always pass -pix_fmt yuv420p.
    Respect visual beat density: Never hold a static frame for longer than 3.0 seconds. If a voiceover clause takes 6 seconds, split the visual state into at least two sub-beats (for example, camera zoom-in at t=2.5s or progressive node reveal).
